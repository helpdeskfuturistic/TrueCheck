SYSTEM STATES

Clear when the answer is unclear.

These are interface states for cases where a claim needs context, evidence is unavailable, or a service fails.

01 / AMBIGUOUS

More context required.

The claim does not identify enough information to determine what should be checked.

02 / INSUFFICIENT

Not enough evidence.

Available sources do not support a reliable conclusion. The system should not guess.

03 / OUT OF SCOPE

This is not a factual claim.

Opinions, instructions, personal requests and unrelated questions should be redirected.

04 / ERROR

Verification unavailable.

Give the user a useful recovery message when retrieval, OCR, speech or an API fails.

OUR APPROACH

Verify information.
Not assumptions.

TrueCheck is designed to help people evaluate factual claims using available evidence. It should communicate uncertainty clearly and never present a guess as a verified fact.

01

Submit

Enter a claim, upload a file, paste a URL or speak naturally.

02

Analyze

Identify whether the input contains a factual claim that can be checked.

03

Verify

Compare the claim with relevant, credible and traceable evidence.

04

Explain

Present the findings, sources and limitations in clear language.
